# Mayhem Oracle overlay (Tauri + React + TypeScript)

Desktop companion overlay for ARAM Mayhem. Vite frontend + Tauri (Rust) shell.

## Runtime configuration

`MAYHEM_API_BASE` selects the web API the member coach talks to. It is read by
the **Rust** process at launch (`src-tauri/src/member.rs`), so it must be a
real environment variable in the shell that starts Tauri — it is *not* a
`VITE_*` variable and is *not* loaded from any `.env` file.

- Unset → the member coach banner shows `api-base-not-configured`.
- Set, signed out → the banner shows `unauthenticated` (expected until
  overlay device-linking ships).

From the repo root, the deterministic dev launch is:

```bash
npm run overlay:dev                                   # defaults to https://wasfun.lol
MAYHEM_API_BASE=http://localhost:3000 npm run overlay:dev   # against a local `npm run dev`
```

No secrets belong in this variable — it is a public origin only.

Bundled game data under `public/data/` is untracked and regenerated by
`npm run sync-data` (runs automatically before `dev` and `build`).
